# merekel_ykshaqyru

Запуск (Node.js 18+):

    npm install
    JWT_SECRET=длинная-строка TELEGRAM_BOT_TOKEN=токен_бота npm start

Откройте http://localhost:3000

Настройки:
- public/index.html, вверху скрипта: MANAGER_WA (WhatsApp менеджера) и PRICE (цена, только показывается).
- public/music.mp3: фоновая музыка (один файл на весь сервис).
- public/i18n.js: языки, категории, шаблоны (THEMES), тексты.
